## Microsoft SQL Server

`mssql.svg` is the unmodified blue **SQL Server 2025** SVG currently used on [Microsoft's official SQL Server page](https://www.microsoft.com/en-us/sql-server), checked on November 1, 2026. The page names Microsoft SQL Server 2025 as its featured product and references this [official SVG asset](https://cdn-dynmedia-1.microsoft.com/is/content/microsoftcorp/1065066-Icon-SQLServer-16x16). The SVG has a `0 0 16 16` viewBox and remains scalable at the toolkit's display size. Its original gradients, geometry, and transparent background are preserved. It replaces the earlier red-and-gray Devicon icon while retaining the existing local filename and technology aliases.

Microsoft owns this name and logo; the Devicon MIT license does not apply to this separately sourced asset. It is displayed only to identify the database technology, without implying endorsement. See [Microsoft's trademark and brand guidelines](https://www.microsoft.com/en-us/legal/intellectualproperty/trademarks).

## Render

`render.svg` is the unchanged favicon linked by [Render's official homepage](https://render.com/) on October 27, 2026: [official SVG source](https://render.com/icon.svg?icon.00d01gt742wgb.svg?dpl=7bcf56747d). It is used only to identify the hosting platform. Render owns its name and logo; the Devicon MIT license does not apply to this separately sourced asset.

Dark monochrome icons sit on white icon plates in both interface themes so their original colors do not need to be changed.
